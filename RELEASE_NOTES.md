# Singularity v0.6.2

## What's new

- Added an interactive Help Center for Windows desktop and Android.
- Added guided Xtream setup with safe server URL, username, and password examples.
- Added guided M3U playlist and XMLTV EPG source setup, plus non-destructive playlist and EPG removal guidance.
- Added tours for Home, Live TV, Movies, Series, Multiview, the EPG Guide, and player language, subtitle, and technical-stat controls.
- When no playlists are active, the Xtream setup guide now opens automatically on the Login screen.
- Replaced the Help navigation question-mark icon with a clear Help label.

## Install

- **Windows:** Run the `.exe` installer or `.msi` package.
- **Android:** Enable installation from unknown sources, then install the APK.
